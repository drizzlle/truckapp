Overview

Base URL: https://truckapp-nine.vercel.app/api (Development)

Production URL: https://truckapp-nine.vercel.app/api

Content Type: application/json

Authentication: JWT (JSON Web Tokens)

API Version: 1.0

Key Features

  • User registration (Customer & Driver)
  • JWT authentication with token refresh
  • Job creation with real-time pricing calculation
  • Complete job lifecycle management
  • Real-time location tracking
  • Payment processing (Paystack integration)
  • Bidirectional rating system
  • Driver availability management
  • Push notifications (FCM)
  • Distance-based driver matching
Production Ready: The API is production-ready with real pricing calculation, state machine validation, and comprehensive security features.

Quick Start for Frontend Developers

Step 1: Get Configuration Data

Before creating jobs, fetch available vehicle types and item categories:

GET /api/config/vehicle-types/ GET /api/config/item-categories/

Step 2: Register Users

POST /api/auth/register/customer/ POST /api/auth/register/driver/

Step 3: Login

POST /api/auth/login/ Response: { "access": "token_here", // Valid for 1 hour "refresh": "token_here" // Valid for 7 days }

Step 4: Make Authenticated Requests

// Add to all authenticated requests Headers: { "Authorization": "Bearer YOUR_ACCESS_TOKEN", "Content-Type": "application/json" }

Step 5: Create a Job

POST /api/jobs/ // See full example in Jobs section

How to Use:

  1. Download and install Postman
  2. Download the collection file: POSTMAN_COLLECTION.json from project root
  3. Import into Postman (Import button → Upload Files)
  4. Create environment with these variables:
    base_url: http://localhost:8000/api access_token: (auto-set after login) refresh_token: (auto-set after login) job_id: (auto-set after job creation)
  5. Start testing! The collection includes all endpoints with sample data

Test Flow:

  1. Configurations → List Vehicle Types (save ID)

Authentication

The API uses JWT tokens for authentication. All protected endpoints require an access token.

Token Lifecycle

Token Type Valid Duration Purpose
Access Token 1 hour Used for API authentication
Refresh Token 7 days Used to get new access token

How to Use Tokens

// Include in request headers Authorization: Bearer {access_token} // When access token expires (after 1 hour): POST /api/auth/token/refresh/ { "refresh": "your_refresh_token" } // Response: { "access": "new_access_token" }
Best Practice: Store tokens securely (AsyncStorage/Keychain for mobile, HttpOnly cookies for web). Never expose tokens in URLs or logs.

Job Status Workflow

Jobs follow a strict state machine. Invalid transitions will be rejected.

1. pending
    ↓ Driver accepts job
2. driver_assigned
    ↓ Customer confirms pickup
3. pickup_confirmed
    ↓ Driver starts delivery
4. in_transit
    ↓ Driver marks as delivered
5. delivered
    ↓ Customer confirms delivery
6. completed

Alternative Paths

  • Cancellation: Can happen from pending, driver_assigned, or pickup_confirmed → cancelled_by_customer / cancelled_by_driver
  • Dispute: Can be created from delivered status → disputed
  • Dispute Resolution: disputed → completed (admin action)
Important: You cannot skip steps. For example, you cannot go from "pending" directly to "in_transit". Each step must be completed in order.

Error Responses

HTTP Status Codes

Code Meaning Description
200 OK Request successful
201 Created Resource created successfully
400 Bad Request Invalid request data or validation error
401 Unauthorized Missing or invalid authentication token
403 Forbidden Insufficient permissions (e.g., driver trying to create job)
404 Not Found Resource not found
500 Server Error Internal server error

Error Response Format

{ "error": "Error message here" } // OR for validation errors: { "field_name": ["Error message for this field"], "another_field": ["Another error message"] }

Common Errors

Authentication Error (401)

{ "detail": "Authentication credentials were not provided." } // OR { "detail": "Given token not valid for any token type" }

Validation Error (400)

{ "email": ["This field is required."], "phone_number": ["Phone number already registered"], "password": ["This password is too short. It must contain at least 8 characters."] }

Permission Denied (403)

{ "error": "Only customers can create jobs" } // OR { "error": "Only drivers can accept jobs" }

State Transition Error (400)

{ "error": "Cannot transition from 'pending' to 'completed'" }

Weight Capacity Error (400)

{ "items": "Total weight (150.5kg) exceeds vehicle capacity (100kg)" }

React / React Native Example

// api.js - Create this helper file const API_BASE = 'http://localhost:8000/api'; let accessToken = null; let refreshToken = null; // Login function export async function login(email, password) { const response = await fetch(`${API_BASE}/auth/login/`, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ email, password }) }); const data = await response.json(); if (response.ok) { accessToken = data.access; refreshToken = data.refresh; // Save to AsyncStorage/localStorage return data.user; } else { throw new Error(data.error || 'Login failed'); } } // Authenticated request helper export async function apiCall(endpoint, options = {}) { const headers = { 'Content-Type': 'application/json', ...options.headers }; if (accessToken) { headers['Authorization'] = `Bearer ${accessToken}`; } let response = await fetch(`${API_BASE}${endpoint}`, { ...options, headers }); // Handle token refresh if expired if (response.status === 401 && refreshToken) { const refreshResponse = await fetch(`${API_BASE}/auth/token/refresh/`, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ refresh: refreshToken }) }); if (refreshResponse.ok) { const refreshData = await refreshResponse.json(); accessToken = refreshData.access; // Retry original request headers['Authorization'] = `Bearer ${accessToken}`; response = await fetch(`${API_BASE}${endpoint}`, { ...options, headers }); } } return response.json(); } // Usage examples: // Create a job async function createJob(jobData) { try { const job = await apiCall('/jobs/', { method: 'POST', body: JSON.stringify(jobData) }); console.log('Job created:', job); return job; } catch (error) { console.error('Error:', error); } } // List jobs async function getJobs(status = null) { const url = status ? `/jobs/?status=${status}` : '/jobs/'; return await apiCall(url); } // Calculate price before creating job async function calculatePrice(priceData) { return await apiCall('/config/calculate-price/', { method: 'POST', body: JSON.stringify(priceData) }); }

Flutter / Dart Example

// api_service.dart import 'package:http/http.dart' as http; import 'dart:convert'; class ApiService { static const String baseUrl = 'http://localhost:8000/api'; static String? accessToken; static String? refreshToken; // Login static Future<Map<String, dynamic>> login(String email, String password) async { final response = await http.post( Uri.parse('$baseUrl/auth/login/'), headers: {'Content-Type': 'application/json'}, body: jsonEncode({'email': email, 'password': password}), ); if (response.statusCode == 200) { final data = jsonDecode(response.body); accessToken = data['access']; refreshToken = data['refresh']; // Save to secure storage return data['user']; } else { throw Exception('Login failed'); } } // Authenticated request static Future<dynamic> apiCall( String endpoint, { String method = 'GET', Map? body, }) async { final headers = { 'Content-Type': 'application/json', if (accessToken != null) 'Authorization': 'Bearer $accessToken', }; final uri = Uri.parse('$baseUrl$endpoint'); http.Response response; if (method == 'GET') { response = await http.get(uri, headers: headers); } else if (method == 'POST') { response = await http.post( uri, headers: headers, body: jsonEncode(body), ); } else if (method == 'PATCH') { response = await http.patch( uri, headers: headers, body: jsonEncode(body), ); } else { throw Exception('Unsupported method'); } // Handle token refresh if (response.statusCode == 401 && refreshToken != null) { final refreshResponse = await http.post( Uri.parse('$baseUrl/auth/token/refresh/'), headers: {'Content-Type': 'application/json'}, body: jsonEncode({'refresh': refreshToken}), ); if (refreshResponse.statusCode == 200) { final data = jsonDecode(refreshResponse.body); accessToken = data['access']; // Retry request return await apiCall(endpoint, method: method, body: body); } } return jsonDecode(response.body); } // Create job static Future<Map<String, dynamic>> createJob(Map<String, dynamic> jobData) async { return await apiCall('/jobs/', method: 'POST', body: jobData); } // Get vehicle types static Future<List> getVehicleTypes() async { return await apiCall('/config/vehicle-types/'); } }

JavaScript / Axios Example

// axiosConfig.js import axios from 'axios'; const api = axios.create({ baseURL: 'http://localhost:8000/api', headers: { 'Content-Type': 'application/json', }, }); // Request interceptor to add token api.interceptors.request.use( (config) => { const token = localStorage.getItem('access_token'); if (token) { config.headers.Authorization = `Bearer ${token}`; } return config; }, (error) => Promise.reject(error) ); // Response interceptor to handle token refresh api.interceptors.response.use( (response) => response, async (error) => { const originalRequest = error.config; if (error.response.status === 401 && !originalRequest._retry) { originalRequest._retry = true; try { const refreshToken = localStorage.getItem('refresh_token'); const response = await axios.post( 'http://localhost:8000/api/auth/token/refresh/', { refresh: refreshToken } ); const { access } = response.data; localStorage.setItem('access_token', access); originalRequest.headers.Authorization = `Bearer ${access}`; return api(originalRequest); } catch (refreshError) { // Redirect to login window.location.href = '/login'; return Promise.reject(refreshError); } } return Promise.reject(error); } ); export default api; // Usage: // import api from './axiosConfig'; // const jobs = await api.get('/jobs/'); // const newJob = await api.post('/jobs/', jobData);
Pro Tips:
  • Always handle token refresh automatically in your API client
  • Store tokens securely (never in localStorage for sensitive apps)
  • Test all endpoints with Postman before integrating
